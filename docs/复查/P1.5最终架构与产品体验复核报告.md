# P1.5 最终架构与产品体验复核报告

## 最终裁定

P1.5 通过，可以停止本阶段开发。UNIT-21 已关闭首次启动隐式目录问题，UNIT-22 已关闭 CLI 成功响应后的 Windows fast-fail，UNIT-23 又将 AI hook 的同类风险收敛到共享 IPC 传输层。当前没有必须在进入 P2 前继续修改的已知阻塞项。

这不代表产品已经达到开源 v1.0。当前成果是一个可真实运行、可量化验收的 Windows 核心工作流；产品身份、安装发布、环境诊断、设置面和完整可访问性仍属于 P2/P3。

## 产品体验结论

第一版核心心智模型已经稳定：

1. 空工作区首屏不隐式创建终端，用户选择目录后才绑定稳定 `workspaceRoot`。
2. 多个真实 PowerShell/ConPTY 以动态矩阵展示；3×3 只是 9 个窗口在当前尺寸下的计算结果，不是固定上限。
3. 用户主动放大单窗口后，右侧文件树才加载该工作区目录；除主动缩小或从左侧切换目标外，不会自行退出聚焦态。
4. CLI 与 Review 共用左侧窗口列表；Review 只针对当前聚焦仓库，A→B→A 切换不重建 PTY。
5. 文件与行范围引用交给窗口内原生 Codex/Claude CLI 读取，不建立第二套 Agent 对话层。
6. 后台终端继续执行并消费输出，但不可见表面不请求无意义重绘。

已有真实截图证明 9 窗格矩阵、16 窗口聚焦、按需文件树、Review 宽窄屏、旧 Agents 会话回退 CLI、首次空工作区与重启恢复。详细逐图结论继续以《P1.5 产品体验复查报告》为准；UNIT-21 后新增的空工作区与恢复截图位于 `docs/验收/首次工作区生命周期数据/真实首启-20260719-124249/`。

保留问题不阻塞 P1.5：PowerShell profile 错误会原样占据终端，需要 P2 环境诊断帮助普通用户区分 shell 配置与应用故障；1024×720 Review 较拥挤，纯图标控制、约 22px 放大按钮、键盘顺序、Narrator、高对比度和 200% 缩放仍需 P3 实测。

## 架构结论

### 应继续保留的深模块

| 模块 | 价值 | 裁定 |
| --- | --- | --- |
| `paneflow-ipc-client` | 隐藏本地 socket/命名管道、绝对 deadline、Windows 重叠 I/O、取消回收与 framing | 保留为 CLI、MCP、hook 的唯一传输 seam |
| `WorkspaceFocusState` | 用稳定工作区 ID 与根目录表达聚焦上下文 | 保留，但下一阶段应与 `AppMode` 合并为完整展示状态机 |
| `RenderVisibility` | 后台继续运行、隐藏表面不重绘 | 保留，16GB 实测已证明收益 |
| `reference_formatter.rs` | 集中 Common、Codex、Claude、PowerShell 引用格式 | 保留，未来适配器只能复用，不能复制规则 |
| `FilesTreeState` | 以稳定根目录、异步 hydration 和 generation 隔离文件树 | 保留，继续按需加载 |
| `DiffView` | 封装当前仓库 Git 探测、watcher 与只读行模型 | 保留内部核心，外层历史多项目范围后续删除 |

### 下一阶段的架构深化顺序

1. **WorkspaceLifecycle 恢复路径**：GUI 目录选择与 IPC 创建已经共用 append/finish，但会话恢复仍单独构造 Terminal、Pane 与订阅，且缺失保存目录时存在隐式回退风险。应让创建、恢复、Git 准备和 watcher 登记服从同一生命周期 interface；这是推荐的下一项。
2. **WorkspacePresentation 状态机**：当前 `workspace_focus` 与 `AppMode` 可组合出无效状态。后续可收敛为 `Grid` 与 `Focused { workspace, root, surface, view: Cli | Review }` 两类可表示状态，集中切换副作用。
3. **Terminal runtime interface**：`TerminalView` 仍向应用层暴露较多 Alacritty 状态和字段。应按输入、输出快照、生命周期与诊断能力收窄，但必须单独配置 1/9/16 容量与长稳门禁，不能顺手重构。
4. **旧产品壳清理**：公开 Review 只使用当前工作区，但历史 MultiProject、Worktree picker 与不可达 Agents shell 仍保留大量代码。P2 应按可删除批次收窄，而不是继续兼容不可达产品面。

- Release hook Prompt 33.475ms、Stop 16.790ms；GUI 观察到真实 `thinking` 事件。
- CLI 成功、参数错误、目标不存在与离线退出码均保持稳定。
- GUI、PTY、hook 与验收目录关闭后零残留。
- 最终架构可视化：`C:\Users\Administrator\AppData\Local\Temp\architecture-review-AgentWorkspace-20260719-140401.html`，已在本机浏览器打开。
