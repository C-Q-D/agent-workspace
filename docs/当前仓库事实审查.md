## 4. 产品范围与实现边界

### 4.1 已确认产品范围

外层 `agent-workspace/AGENTS.md` 和
`agent-workspace/docs/ai-project/v1完整代码原子任务方案.md` 已确认：

- 产品面向 Windows 开源用户。
- 核心是动态 N×N 真实 PowerShell/ConPTY 终端矩阵。
- 每个窗口绑定稳定 `workspaceRoot`。

- `UserDataLayout` 只计算路径，不在构造时创建目录。

`src-app/src/config_writer.rs`。其中一部分只是旧注释或测试文件名，不能据此推翻
`data_layout.rs` 的真实路径；是否重命名和迁移属于后续配置恢复或公开清理原子。
