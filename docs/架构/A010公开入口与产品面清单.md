# A010 公开入口与产品面清单

## 审查目的与口径

本文记录当前 Windows 构建中用户能够直接进入的启动、菜单、快捷键、命令、设置、模式和
发行入口，并把它们分为三类：

- **AgentWorkspace 核心**：符合 Windows 多 AI CLI 终端工作区定位，应进入 v1 主路径。
- **待隔离 Paneflow 遗留**：当前仍能由用户触达或随发行载荷暴露，但与 v1 边界不一致，
  需要 A014 决策并由 A027～A040 等后续原子处理。
- **仅测试或内部**：源码仍存在，但没有 Windows 公开导航入口，或只用于兼容、测试与
  平台专用路径；不能仅凭模块存在宣称用户可用。

“Action 已注册”只证明 GPUI 可分发该类型，不等于界面存在按钮或默认快捷键；“模式可渲染”
也不等于启动或恢复能进入。下列结论同时核对调用位置、导航位置和恢复约束。

可重复检查：

```powershell
pwsh -NoProfile -File scripts/检查公开产品面清单.ps1
```

## 4. Actions 与默认快捷键

`src-app/src/app/actions.rs:9` 在 `paneflow` 命名空间注册 Action。命名空间仍是内部兼容名，
但 JSON dispatch、默认键位和根视图处理器可能让 Action 真正可达：

- 核心终端/窗口 Action：分屏、关闭窗格/标签、方向聚焦、工作区新建/关闭/选择、复制粘贴、
  搜索、布局、放大、字体缩放、文件侧栏与 Diff。
- 待隔离 Action：`OpenAgentsThreadMenu`、Composer、Broadcast、Attention Queue、
  Launch Pad、Rosetta、MCP/更新相关入口。
- 平台内部 Action：macOS Quit/About/Copy/Paste/SelectAll/OpenHelp；Windows 不通过原生
  菜单安装，但部分同名操作仍可能由自绘控件调用。

根视图在 `src-app/src/main.rs:1765`～`:1853` 注册上述处理器。默认键位和设置页的可重绑
清单分别来自 `src-app/src/keybindings/defaults.rs` 与
`src-app/src/keybindings/registry.rs`。因此 A027 必须同时检查：

1. Action 类型是否存在；
2. 根视图是否注册处理器；
3. 默认或用户键位能否派发；
4. 菜单/按钮是否直接派发。

只删除按钮不足以证明旧产品面不可达。

## 6. `app/mod.rs` 模块登记结论

`src-app/src/app/mod.rs` 同时登记核心模块和上游遗留模块。分类必须依据调用链，而不是文件名：

- 核心：`bootstrap`、`workspace_ops`、`sidebar`、`files_sidebar`、`diff_view_actions`、

- 待隔离：`agents_view_actions`、`agents_sidebar`、`agents_diff`、`agents_bottom_panel`、
  `composer`、`broadcast`、`attention_queue`、`launch_pad`、`rosetta`。
- 内部/需后续依赖审查：更新、IPC、Telemetry、helper 和平台兼容模块不能由本清单决定是否
  编译或打包，A011～A014 将根据 Cargo 和运行时依赖继续判定。

## 7. bootstrap 可达性结论

`PaneFlowApp::new` 同时建立配置 watcher、主题 watcher、Git/files 事件处理、IPC、更新检查、
Telemetry flusher 和工作区恢复，见 `src-app/src/app/bootstrap.rs:1`、`:47`、`:73`、
`:110`、`:293`、`:427`、`:730`。这些后台能力不是菜单项，但会随正常 GUI 启动，必须在
A011/A013 中作为默认构建与资源生命周期审查对象。

bootstrap 已明确做到：

- 保存的 `Diff`/`Agents` 模式不恢复，统一从 `Cli` 启动；
- 旧 Agents 项目不执行启动 Git 扫描、不挂载终端、不注册缓存清理定时器；
- Windows 不安装 macOS 菜单与 Rosetta 翻译提示。

它仍默认提取 MCP bridge、启动更新检查和 Telemetry 相关路径，因此“界面隐藏”不能代替
发行载荷与后台生命周期隔离。

## 9. 已知限制

- 本原子是静态可达性审查，没有运行 GUI 自动点击全部菜单；动态可达性回归属于 A027。
- 用户自定义键位可通过已有 Action 名触达未显示按钮，因此 A027 必须覆盖配置迁移与
  Action dispatch。
- 本文不判断 crate 是否进入最终链接，也不把“源码存在”当作“发行包含”；该结论属于
  A011。
- 文中的行号对应 A010 基线；检查脚本用稳定源码标记定位，后续行号移动不会造成虚假失败。
