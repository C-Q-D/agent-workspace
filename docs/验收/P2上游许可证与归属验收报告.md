## 失败诊断记录

1. 本机首次安装 WiX 时，winget 启用 NetFx3 返回 `0x800F0950`。检查确认 NetFx3 状态为 `DisabledWithPayloadRemoved`；使用 `--force` 只安装 WiX 本体后，`candle.exe` 与 `light.exe` 均真实启动并完成 MSI 编译，证明缺失 payload 没有影响实际工具运行。
2. 首次 MSI 链接在四个中文安装文件名处报 `LGHT0311`。根因是现有 MSI 数据库使用 code page 1252；保留仓库中文源文件名，只将安装后的别名改为 ASCII 后，真实链接通过，没有改变全局 code page。
3. 首次 dark 内容检查按最终安装名搜索提取目录而失败。检查反编译 WXS 后确认 dark 按内部 File Id 提取，五份材料实际都已存在；验收改为同时核对 File Id 字节与 WXS 安装名映射，未因此修改产品打包内容。
4. dark 的 `DARK1059` 是反编译 stock WixUI 时对部分 ControlEvent 外键的已知警告，不影响 File 表、柜体内容或本次法律材料验证。
