# A008-F01 线程与句柄采样缺失根因记录

## 最小复现

```powershell
$source = Get-Content -Raw .\scripts\运行Windows设置稳定性资源门禁.ps1
$source.Contains('threadCount')
$source.Contains('handleCount')
```

A007 提交 `2fe6376` 的两个结果均为 `false`，因此任何正式运行都无法产生 A008 要求的
线程和句柄证据。

## 实际值、期望值与首次偏离

- 实际分组字段只有进程数、累计 CPU、Working Set 和 Private Memory。
- A008 明确要求四阶段同时记录 CPU、私有内存、线程、句柄和子进程。
- 第一次偏离发生在 A007 的资源分组 schema 设计；进程已经正确分组，但两个指标未进入
  样本行。

## 排除项

- 四个阶段共用同一个采样函数，排除了单个阶段漏写。
- 进程树已经包含宿主和后代，排除了无法取得目标进程集合。
- `Get-Process.Threads.Count` 与 `HandleCount` 在当前真实 PowerShell 进程上可直接读取，
  不需要产品代码或额外常驻采集器。

## 根因修复

在每个既有资源组内汇总成员的线程数与句柄数；空组保持零。修复不改变组归属、采样间隔、
阶段时长或门禁阈值，并由脚本契约测试固定字段名。
