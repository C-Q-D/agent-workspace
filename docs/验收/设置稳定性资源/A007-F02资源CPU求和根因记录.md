# A007-F02 资源 CPU 求和根因记录

## 最小复现

```powershell
@(Get-Process -Id $PID) | Measure-Object TotalProcessorTime -Sum
```

PowerShell 稳定报告 `TimeSpan` 输入“not numeric”，求和结果为空。

## 实际值、期望值与首次偏离

- `Get-Process.TotalProcessorTime` 的类型是 `System.TimeSpan`。
- 资源门禁需要的是各进程累计 CPU 毫秒之和。
- 第一次偏离发生在分组采样投影：旧表达式把 `TimeSpan` 直接交给只接受数值的
  `Measure-Object -Sum`，实际模式会在首个样本失败。

## 排除项

- 单进程最小复现即可失败，排除了进程树竞争、空进程组与 GUI 生命周期。
- `WorkingSet64` 和 `PrivateMemorySize64` 本身是数值，同类求和探针正常，排除了整个
  分组汇总设计。
- 错误在读取任何证据文件前出现，与路径、配置 watcher 和终端输出无关。

## 根因修复

先把每个 `TimeSpan` 投影为 `TotalMilliseconds` 数值，再执行求和；空分组仍自然得到
零值。契约测试禁止重新引入 `Measure-Object TotalProcessorTime -Sum`，不改变资源
分组、采样频率或阶段时长。
