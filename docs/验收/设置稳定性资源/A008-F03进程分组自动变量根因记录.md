# A008-F03 进程分组自动变量重绑定根因记录

## 最小复现

A008 第一次真实运行在首个冷启动样本稳定失败：

```text
Where-Object: The property 'Id' cannot be found on this object.
```

失败位置是 `Get-ResourceGroup` 的宿主分支；运行时间 2.7 秒，尚未创建 9 个终端。

## 实际值、期望值与首次偏离

- `Where-Object` 外层的 `$_` 是 `System.Diagnostics.Process`。
- PowerShell 进入 `switch ($Group)` 后，会把同一个自动变量 `$_` 重绑定为当前 switch
  输入字符串，例如 `host`。
- 宿主分支随后读取 `$_.Id`，实际是在字符串上读取 `Id`；第一次偏离发生在资源分组
  谓词，不在进程树采集。

## 排除项

- 失败发生在一个终端都未创建的冷启动阶段，排除了 9/16 容量、ConPTY 和输出负载。
- 进程树中的根进程已由 `Get-Process` 成功取得，排除了 PID 复用和进程提前退出。
- finally 清理后 AgentWorkspace 进程数为零，排除了残留进程影响下一轮。
- 同一表达式对四种分组都存在自动变量重绑定风险，不是宿主名称识别错误。

## 根因修复

进入 `switch` 前用局部变量 `$ProcessItem` 保存外层管道进程，所有分支只读取该变量。
契约测试同时要求局部冻结语句存在，并禁止宿主分支重新使用 `$_.Id`。修复不改变分组
定义、采样频率、资源字段或进程生命周期。
