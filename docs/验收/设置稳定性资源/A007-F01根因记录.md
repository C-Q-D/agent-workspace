# A007-F01 高频采样错误文本断言根因记录

## 最小复现

```powershell
pwsh -NoProfile -File .\scripts\运行Windows设置稳定性资源门禁.ps1 `
  -SelfCheck `
  -BinaryPath .\target\release\agent-workspace.exe `
  -SampleIntervalMilliseconds 499
```

稳定结果为退出码 `1`，实际错误包含参数名 `SampleIntervalMilliseconds`、传入值 `499`
和最小值 `500`。

## 实际值、期望值与首次偏离

- 门禁实际行为符合预期：`ValidateRange(500, 10000)` 在脚本主体执行前拒绝 `499`。
- 测试期望错误文本包含实现标记 `ValidateRange`。
- 本机 PowerShell 7 的参数绑定错误使用英文自然语言描述，没有输出 `ValidateRange`
  标记；第一次偏离发生在测试脚本的错误文本断言，不在门禁参数约束。

## 排除项

- 非零退出码排除了“门禁接受了高频采样”的候选原因。
- 错误同时给出参数名与最小值，排除了二进制校验、路径解析或 SelfCheck 主体失败。
- 同一命令重复执行结果一致，不是时序、进程或文件系统竞争。

## 根因修复

测试继续强制非零退出，但只匹配跨 PowerShell 版本稳定的语义：参数名
`SampleIntervalMilliseconds` 与下界 `500`。修复不改变生产脚本、不降低采样下界，
也不会把其他参数或二进制错误误判为通过。
