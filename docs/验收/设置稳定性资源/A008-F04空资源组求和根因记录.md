# A008-F04 空资源组求和根因记录

## 最小复现

A008 第二次真实运行在首个冷启动样本稳定失败：

```text
Measure-ResourcePhase: The property 'Sum' cannot be found on this object.
```

独立探针结果：

```text
@() | Measure-Object WorkingSet64 -Sum  -> 无输出
@() | Measure-Object HandleCount -Sum  -> 无输出
@() | ForEach-Object { <数值> } | Measure-Object -Sum -> 统计对象，Sum 可转为 0
```

## 实际值、期望值与首次偏离

- 冷启动阶段没有 Shell 或 CLI 是合法状态，这两个分组成员数组为空。
- 门禁期望空分组的资源总量和数量为零。
- 第一次偏离发生在 Working Set、Private Memory 和 Handle 的属性式求和；零输入时
  `Measure-Object <Property> -Sum` 不产生对象，随后读取 `.Sum` 必然失败。

## 排除项

- A008-F03 后进程分组已能推进到数值汇总，排除了自动变量重绑定。
- 宿主分组非空，而错误仅需一个合法空组即可触发，排除了 GUI 提前退出。
- CPU 和线程先投影标量的同类表达式在空数组探针中可安全得到零，证明无需伪造成员。
- finally 清理后 AgentWorkspace 进程数为零。

## 根因修复

Working Set、Private Memory 和 Handle 先逐成员投影为数值，再使用无属性
`Measure-Object -Sum`。这样空组自然转为零，非空组保持真实求和；契约测试禁止重新
引入三种属性式求和。采样频率、阶段、分组和产品进程均不改变。
