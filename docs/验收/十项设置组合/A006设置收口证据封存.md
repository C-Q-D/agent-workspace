```powershell
cargo build --release -p paneflow-app
```

```powershell
pwsh -NoProfile -File scripts/运行Windows十项设置组合验收.ps1 `
  -SelfCheck `

```

执行真实验收：

```powershell
pwsh -NoProfile -File scripts/运行Windows十项设置组合验收.ps1 `
  -BinaryPath target/release/agent-workspace.exe `
```

设置控件完成两轮目标；不得直接修改两轮 JSON。
