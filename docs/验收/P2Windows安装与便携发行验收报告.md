# P2-03 Windows 安装与便携发行验收报告

## 结论

P2-03 于 2026-07-19 验收通过。AgentWorkspace 0.7.11 已形成两种可交付的 Windows x64 发行形态：per-machine MSI 和无需安装的便携 ZIP。本机真实完成 0.7.10 初装、0.7.11 MajorUpgrade、已安装程序探针、0.7.11 卸载、便携包重复构建、真实解压和便携程序探针；升级和卸载均未修改项目哨兵或 `.agent-workspace` 用户数据哨兵。

MSI 与 ZIP 的主程序、17 个 helper、GPL RTF 和五份法律材料共 24 个共享文件逐字节一致。ZIP 唯一额外文件是中文《便携版说明》。非破坏性总门禁汇总既有生命周期证据后，再次验证当前产物哈希、共享载荷、完整应用测试、许可证门禁和系统零残留，全部通过。

机器结果见 [Windows 发行总验收数据](Windows发行数据/Release-20260719-191129/总验收结果.json)。

## 便携与载荷一致性

- 打包器只使用 PowerShell 与 .NET 标准库，不调用 Cargo、WiX 或安装器。
- ZIP 条目顺序、DOS 时间戳和压缩参数固定；相同输入连续生成的文件字节一致。
- 非法版本、缺失 helper、真实 EXE 单字节变化都会被门禁识别。
- 真实解压后 25 个条目逐项与 ZIP 的长度和 SHA-256 一致。
- 隔离 `USERPROFILE` 中运行主程序输出 `agent-workspace 0.7.11`，退出码 0。
- 便携运行不把解压目录作为数据目录；开发者现有 `.agent-workspace` 指纹未变化。
- WiX `dark` 解包确认 MSI File 表 24 项，全部与 ZIP 对应条目逐字节一致；便携说明是 ZIP 唯一额外项。
