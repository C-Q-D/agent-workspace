# 第一版性能验收报告

## 当前结论

截至 2026-07-18，1、9、16 个真实 Windows PowerShell/ConPTY 终端的容量与切换验收，以及 9 终端连续 30 分钟长稳验收均通过。16 终端主进程峰值 Working Set、三个容量点的主进程平均 CPU、窗口切换 P95、后台输出完整性、PTY 进程稳定性、长稳内存趋势和关闭清理均满足第一版预算。

## 验收环境

- 操作系统：Windows 11 专业版，Build 26200。
- 处理器：13th Gen Intel(R) Core(TM) i7-13700H，20 个逻辑处理器。
- 内存：31.6 GiB。
- 构建：启用 `terminal-perf-metrics` 的 Release 二进制。
- 二进制 SHA-256：`14ACD3BB04008C89BF56AD79D29F4C2B72031EAC85B3E0639E0C08514E73CED1`。
- 负载：每个 workspace 启动独立的真实 PowerShell 子进程，每 250 ms 输出一条带窗口编号和时间戳的记录；未使用 mock 终端或伪造进程数据。
- 采样：每个容量点连续采样 30 秒，随后读取全部终端最终标记、执行 32 次真实 `surface.focus` 切换并正常关闭应用。

Working Set 从 1 到 9 终端的边际增量约为 3.702 MiB/终端，从 9 到 16 终端约为 2.502 MiB/终端；两个容量区间的中位估计为 3.102 MiB/终端，低于 8 MiB/终端预算。16 终端峰值 Working Set 为 231.289 MiB，低于 256 MiB 预算。Private 指标单独列出，不与 Working Set 预算混用。

三个容量点均在持续输出压力下低于 1% 主进程平均 CPU。该条件强于“空闲 CPU 不高于 1%”的最低门禁，但只代表本机、本构建和本轮负载，不能外推为所有硬件上的固定值。

## 30 分钟长稳结果

9 个 workspace 各自运行独立 PowerShell 持续输出负载。原始运行从第一条采样 `2026-07-18T10:57:03.8082745Z` 开始，完整 30 分钟窗口截止到 `2026-07-18T11:27:03.8082745Z`，窗口内包含 1576 条真实采样。

- 启动收敛后的 1547 条采样始终保持 18 个 PowerShell 进程，即 9 个终端父 shell 加 9 个负载子进程；没有 PTY 或负载异常退出。
- 完整进程树在其中 1545 条采样为 28 个进程，只有两条出现 30 个进程，且 PowerShell 数量不变，属于短暂非终端辅助进程。
- 30 分钟窗口主进程平均 CPU 为 0.3912%。
- 主进程 Private 从 204.242 MiB 上升后进入约 227 MiB 稳定区间；最后两个五分钟区间均值分别为 227.09 MiB 和 226.92 MiB，没有持续线性增长。
- 主进程 Working Set 在持续输出期进入约 226 MiB 区间；有界负载结束后回落到约 190.75 MiB。峰值为 228.793 MiB。
- 9 个终端均读到最终标记，负载结束后的 64 次切换 P95 为 63.117 ms，切换前后 PowerShell PID 不变，正常关闭后残留进程为 0。

原始结果中的 `ProcessTreeStableDuringSample=false` 和 `ProcessIdsStableDuringSample=false` 是验收器旧采样节拍造成的假阴性：旧实现每轮固定睡眠一秒后再枚举进程，1800 个样本实际跨越约 34 分钟，因此把 30 分钟 45 秒后有界负载的计划内退出也纳入了“采样期间”。绝对一秒节拍修复后，2 个真实终端的 10 个样本首末跨度为 9.021 秒，进程树与 PID 均稳定。长稳产品结论采用原始 CSV 的真实前 30 分钟窗口，不改写原始 JSON。

## 重绘门控与输出完整性

- 9 终端：放大终端采样期 192 次画面变化全部立即请求重绘；后台终端 193 次画面变化全部被门控抑制。
- 16 终端：放大终端采样期 206 次画面变化全部立即请求重绘；后台终端 205 次画面变化全部被门控抑制。
- 1、9、16 三个容量点均读到每个真实 PowerShell 负载的 `AGENTWORKSPACE_DONE` 最终标记，证明缩小或隐藏只抑制 UI 重绘，没有暂停 PTY 读取或丢失尾部输出。
- 32 次循环切换前后 PowerShell PID 集合不变，说明聚焦切换没有重启终端进程。

## 结论边界

- 本报告是单台 Windows 11 机器、单个 Release 构建的验收结果，不代表不同硬件、不同 shell 或真实 Codex/Claude 长任务的资源上限。
- 容量测试将应用主进程与 PowerShell 子进程分开报告；CLI 模型进程、MCP 服务和语言服务器的内存不计入应用自身 256 MiB 门槛。
- 30 分钟长稳运行保留原始假阴性字段并在上文解释，避免通过事后改写数据制造“全绿”结果。
