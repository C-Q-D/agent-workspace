# A022 会话核心所有权验收

## 结论

A022 已在现有 `Workspace` 深模块内建立最小 `WindowSession` 聚合根：

- `WindowSession` 唯一持有稳定会话 ID、创建时绑定的 `workspaceRoot`、当前/保存布局
  和布局叶节点中的真实终端实体。
- 终端生命周期聚合查询、放大布局、窗格收集与会话布局序列化均由
  `WindowSession` 提供。
- `Workspace` 继续保存标题、Git 派生元数据、文件树展开偏好和其他 UI 状态，没有
  把 Git 实现或文件树缓存塞入会话聚合根。
- 迁移期 `Deref` 只把既有字段访问转发到唯一 `session` 字段，不复制 PTY、布局或
  root；A023～A025 将继续把写入入口收敛为显式生命周期方法。
- `0` ID 和空 root 在统一构造边界被拒绝；相同 ID 重新绑定不同 root 的冲突可测试。
  不同会话 ID 允许共享同一个仓库目录，以支持同仓库并行运行多个 CLI。

A021 的 A022 目标态红灯已改为真实类型/API 断言并移除 `ignore`；目前只剩 A024 的
ActiveContext 重复 root 红灯。

实现中出现的唯一质量门禁问题是测试专用 `WorkspaceRootMismatch` 枚举分支在生产构建
中未使用。根因是测试方法已有 `cfg(test)`，其专用错误分支没有同步编译边界。修正把
该分支置于相同测试边界，没有使用 `allow(dead_code)` 隐藏警告。

## 范围边界

A022 没有改变 Shell 设置触发的终端重启、工作区关闭动作或 ActiveContext 派生规则，
也没有增加 watcher、轮询或后台服务。三类终端生命周期入口由 A023 迁移；活动上下文
重复 root 由 A024 删除。
