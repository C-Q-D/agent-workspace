# Windows 安装版与便携版联合数据边界验收报告

## 结论

ATOM-36-03 于 2026-07-19 验收通过。同一隔离 Windows 用户依次运行真实 0.7.11 MSI 安装版和由当前 Release 生成的真实便携 ZIP，两种发行形态共同使用 `%USERPROFILE%\.agent-workspace`，能够双向读取同一组工作区会话。删除 `cache/` 后，两种发行形态都能独立重建相同的 PowerShell shell 资产，且 `config / sessions / state / bin` 四个 durable 目录与 `logs/` 在两次重建中保持字节不变。

便携程序目录在运行期间没有产生 `.agent-workspace` 或修改自身载荷；删除便携目录不影响用户数据。卸载 MSI 后，安装目录和产品注册被清除，用户数据仍完整。五次真实桌面运行全部正常退出，最终进程残留为 0。

精简机器结果见 [运行结果](Windows用户数据边界数据/Distribution-20260719-201436/运行结果.json)。完整安装器日志、应用标准输出和临时发行产物只保留在本机忽略的 `target/` 目录，不进入 Git 历史。

## 根因诊断记录

1. 首次运行在枚举卸载注册表时停止。根因是严格模式下部分系统注册项没有 `DisplayName` 字段；过滤逻辑改为先判断字段存在，再比较产品名。
2. 第二次运行在工作区轮询处停止。源码确认 `workspace.list` 的字段是 `title` 而不是 `name`；修正验收脚本后，已创建会话本身证明产品行为正常。
3. 初次完整目录门禁发现 `sessions/` 在缓存重建运行中变化。对比真实 JSON 后确认是新建 surface 的隐式 `cwd` 在首次恢复时规范化，与缓存无关；增加独立稳定化运行后再取指纹，安装版和便携版的两次缓存重建均通过严格字节门禁。

每个失败现场都先保留并确认根因，随后只卸载 ProductCode 与预期 MSI 完全匹配的受控测试产品，没有通过重试或删除用户数据掩盖问题。
