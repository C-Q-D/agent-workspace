## 架构结果

`WorkspaceLifecycle` 现在是显式创建与会话恢复之间的深模块接缝，接口只暴露恢复根目录规划、稳定生命周期回执、终端/窗格构造和批量登记；失效路径策略、事件订阅、稳定 ID 回填、Git 批次合并和 watcher 登记被隐藏在接缝后。

删除该模块会让根目录过滤、活动索引映射、终端/窗格订阅和 Git 生命周期顺序重新散落到 `session.rs`、`bootstrap.rs`、`workspace_ops/mod.rs` 与 IPC 创建入口，满足本单元定义的删除测试。下一阶段仍停在 P2-01 之前。
