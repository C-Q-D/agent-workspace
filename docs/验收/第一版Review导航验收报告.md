## 验收结论

UNIT-17 通过真实 Windows 验收。Review 模式左侧持续显示工作区窗口列表，右侧显示
当前工作区的改动文件；使用真实鼠标执行 A→B→A 后，活动卡片、标题、Diff 正文和
右侧改动文件均同步切换。两个 PowerShell/ConPTY 在切换期间持续输出且 PID 不变，
应用正常关闭后完整实验进程树零残留。

## 真实场景

1. 创建两个一次性本地 Git 仓库 `Review-A` 与 `Review-B`，分别提交基线文件
   `ONLY_A.txt` 与 `ONLY_B.txt`，再各自追加一行形成真实工作区改动。
2. 在 Release 应用中创建两个绑定上述仓库的真实工作区，每个工作区使用独立的
   PowerShell/ConPTY，并持续每 500 毫秒输出一次标记。
3. 真实点击左侧 `Review-A` 进入应用级聚焦，再发送 Windows 默认快捷键
   `Ctrl+Shift+G` 进入 Review。
4. 真实点击 `Review-B`，随后把窗口缩放为 1024×720，再点击返回 `Review-A`。
5. 读取真实 IPC 活动索引与终端滚动缓冲，采样应用外壳 CPU/内存，最后正常关闭并
   按 PID 与启动时间核对完整进程树。
