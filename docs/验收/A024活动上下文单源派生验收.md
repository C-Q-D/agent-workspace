# A024 活动上下文单源派生验收

## 结论

A024 已删除展示状态中的第二份 `workspaceRoot`：

- `FocusedWorkspaceContext` 只保存稳定 `workspace_id` 和当前终端 Surface，不再复制目录。
- `DisplayCommand::FocusWorkspace` 只携带稳定 ID；A→B 切换按 ID 替换上下文并清除
  A 的 Surface。
- `PaneFlowApp::active_context_workspace` 按聚焦 ID 查找对应
  `WindowSession` 所属工作区，不使用 `active_idx` 推测右侧上下文。
- 文件树打开与重定向在同一次会话查找中取得稳定 `workspace_root()` 和该会话的
  展开状态，避免索引重排时混用两个工作区。
- Git Review 挂载、Project worktree seed 和 Review 交互均使用上述聚焦会话入口。
- Grid、已关闭会话或失效 ID 不存在活动会话，因此不会得到文件/Git root。

文件树实体内部的 `FilesTreeState.root` 只是一次已验证加载任务的缓存身份；异步结果仍以
root 相等性检查拒绝陈旧返回，不构成第二份活动会话身份。Diff 缓存同样只保存已暂停的
计算结果，并由当前聚焦会话派生的 repo key 决定是否挂载。
