# AgentWorkspace 用户设置契约

## 目的

AgentWorkspace 的第一版 Windows 设置服务于“普通 PowerShell 中按需运行 Codex CLI、
Claude Code CLI”的核心流程。设置页提供轻量偏好，不接管 CLI 自身账号、模型、MCP、
权限或订阅配置，也不要求用户通过应用按钮启动 Agent。

全部设置保存在用户目录下的 `.agent-workspace/config/settings.json`。应用内写入采用原子
读改写：只更新目标字段，保留其他已知设置和未来版本的未知字段。删除或恢复某个设置的
默认值，不应清空同文件中的其他设置。

## 七类稳定设置

| 设置类别 | 页面 | 配置键 | 默认行为 | 生效时机 | 恢复默认 |
|---|---|---|---|---|---|
| 默认 Shell | General | `default_shell` | Windows 优先可用的 PowerShell | 下次创建或恢复终端 | 重新选择 System default |
| Claude/Codex 常用命令 | AI Agent | `claude_code_command`、`codex_command` | `claude`、`codex` | 下次点击可选启动按钮或恢复对应 Agent 会话 | 清空自定义命令 |
| 主题 | Appearance | `theme_mode`、`theme` | 跟随现有默认主题 | 当前窗口即时重绘 | 选择 System/default theme |
| 终端字体 | Terminal | `font_family`、`font_size` | 系统可用等宽字体与 13px | 当前终端在短缓存窗口后热更新 | 字体恢复系统默认，字号调回 13px |
| 新工作区引用格式 | General | `default_reference_format` | Common | 下次显式创建工作区 | 选择 Common |
| 工作区矩阵密度 | General | `workspace_grid_density` | Auto（320×190） | 当前矩阵即时重排 | 选择 Auto |
| Git 自动初始化 | General | `git_auto_init` | 开启 | 下次显式创建或有效恢复非 Git 工作区 | 重新开启 |

主题、终端字体和矩阵密度只改变当前界面，不创建或重启 Terminal Surface。默认 Shell 和
Agent 命令不会改写已经运行的 PowerShell。引用格式与 Git 策略不会追溯覆盖已保存工作区；
用户恢复会话时仍使用该工作区自己的引用格式和仓库状态。

## 常用命令的用户流程

正常流程仍是新建终端，然后手动输入 `claude`、`codex` 或其他命令。AI Agent 页的命令
字段只用于保存经常使用的完整启动形式，例如 `codex --profile work`；旁边的启动操作把
该命令提交到当前终端，等价于用户自己输入并回车。它不会自动启动、后台重启或建立新的
Agent 运行时，也不会发展为重量级插件管理器。

## 性能边界

- 设置只在用户操作时写盘，不逐帧写入，也不为单个设置建立专用线程。
- 渲染路径只读取内存中的配置快照，不在每帧读取 JSON。
- 文件 watcher 复用统一配置监听，不为十个键分别轮询。
- 矩阵密度只计算几何；显示更多卡片不会额外创建终端。
- Git 策略只在工作区生命周期边界执行，不周期性扫描全部工作区。

## 配置兼容

十个键缺失时保持旧版本默认行为。枚举型字段遇到未知值时只在内存回退安全默认，不主动
改写磁盘；单个字段类型错误不得让其他合法兄弟字段失效。公开字段、类型和完整示例见
`docs/user/configuration/schema.md`。
